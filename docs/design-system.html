01 — Start

Overview

This is a static, self-contained mirror of the live design tokens. It renders with the real brand fonts and the real colour values, so what you see here is what ships. Click any code chip to copy it.

Source of truth lives in the repo, not here. The website is Astro 5 + Tailwind CSS v4. The authoritative token definitions are in src/styles/custom.css (colour values) and src/styles/tailwind.css (the @theme registration, type scale, spacing, shadows, motion). This file is a human-readable copy — see Keeping this in sync.

02 — Start

Principles & rules

The non-negotiables. These keep the site consistent and the CSS small. They come straight from the project's CLAUDE.md.

✓ Do
  • Style with Tailwind v4 utility classes — flex, px-6, bg-accent, text-section-title.
  • Use colour tokens, never raw hex — bg-primary, text-text-muted, border-border.
  • Use the semantic type scale — text-hero, text-section-title, text-body — so sizing stays responsive.
  • Wrap dark areas in class="dark-section" and let the tokens flip automatically.
  • Reach for Darker Grotesque on headings (font-heading) and Manrope on body (default).
✗ Don't
  • No custom CSS classes in <style> blocks (the few existing component classes are the documented exceptions).
  • No inline styles (style="…") — except genuinely dynamic gradients that need a CSS variable.
  • No raw hex codes in markup — bg-[#14A8B0] is banned; use bg-primary.
  • Don't hand-pick arbitrary font sizes — pull from the scale.
  • Don't put lime text on white without using text-secondary-accessible (contrast).
Custom CSS is only permitted in two files: custom.css (colour token definitions) and tailwind.css (@theme, @layer base/components/utilities). Everything else is utilities.

Light vs dark context

The site alternates light and dark sections. Rather than swapping classes everywhere, a wrapper of class="dark-section" re-points the neutral and accent tokens to dark values. Children keep using bg-bg, text-text, bg-accent — and they just work.

Typography

Two voices. Darker Grotesque — tall, condensed, characterful — carries every heading. Manrope — clean and humanist — carries all body copy and UI. Fira Code handles numbers, labels and kickers.

Numbers, kickers, eyebrows · font-mono
01 — STRATEGY   02 — EXPERIENCE   03 — EXECUTION

The rule

Headings (h1–h6) automatically render in Darker Grotesque at line-height: 1 via the base layer. For body, do nothing — Manrope is the page default. Use font-heading only when you need heading type on a non-heading element.

17 — Reference

Keeping this in sync

This file is a hand-maintained mirror, so it can drift. When you change tokens in the repo, mirror them here.

  1. Edit colour values in src/styles/custom.css and the scale/spacing/shadow tokens in src/styles/tailwind.css as usual.
  2. Copy any changed values into the :root and .surface-dark blocks at the top of this file's <style>.
  3. If you add a brand-new element pattern, add a demo section here and a link in the sidebar.
  4. Open this file directly in a browser to verify — no build step required.
Want this to never drift? The alternative is a live Astro route that imports the real stylesheets. Say the word and it can be promoted from a static mirror to a generated /design-system page.
